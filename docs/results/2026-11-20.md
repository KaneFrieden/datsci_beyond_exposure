# Intermediate results — 20 November 2026

This entry covers our intermittent work on s03 from 14 to 20 November.

## Kane & Marie s03: building the lemma inventory

We first checked whether every learning event from s01 could be connected to one lexeme description from s02. All 3,641,179 events had a match, and the join did not add or lose any events.

Next, we counted the special cases marked in s02 and examined what happens when we exclude them. The categories overlap, so their separate counts cannot simply be added up. After excluding wildcards, the shared pronoun lemma `prpers`, lemmas outside our current word pattern, entries without a regular word-class tag, and the one description that s02 could not fully parse, 3,287,622 events remain. The last case is `cannot/can<vaux><pres>+not<adv>`: we do not yet have a reliable rule for treating its two constituent parts as one lemma.

We then compared several minimum intervals since the previous practice of the item. With a minimum of one day, 1,416,876 events remain for 1,363 lemmas. Of these lemmas, 607 have at least 200 events, accounting for 1,354,966 events. This is a possible starting point from our proposal, not yet our final selection. A shorter minimum of six hours would instead retain 1,702,635 events, with 669 lemmas reaching 200 events. The choice therefore changes both the amount of data and which words we could analyse.

The script keeps all lemmas that pass the structural and time filters in the inventory and marks which ones reach the chosen event threshold. It also records the most frequent word-class tag for each lemma, because different lexeme descriptions can share a lemma. We still need to decide how to handle lemmas with mixed word classes in the later models.

We checked the full run using a separate temporary data folder. The figures above describe that trial run; they are not results of a hypothesis test. Before the next analysis, we need to agree on the main time and event thresholds and document the alternative settings we will check.
